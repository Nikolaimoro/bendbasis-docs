---
title: "Legacy API"
description: "Existing public endpoints and their replacements"
---

The original public endpoints remain available during the migration period. Existing integrations can continue using them until a sunset date is announced.

| Legacy endpoint | Replacement |
| --- | --- |
| `GET https://bendbasis.com/api/v1/public/funding/arbitrage` | `GET https://api.bendbasis.com/v1/funding/arbitrage` |
| `GET https://bendbasis.com/api/v1/public/funding/markets` | `GET https://api.bendbasis.com/v1/funding/markets` |
| `GET https://bendbasis.com/api/v1/public/funding/markets/{marketId}/history` | `GET https://api.bendbasis.com/v1/funding/markets/{market_id}/history` |

The new endpoints are not response-compatible with the legacy API.

<Warning>
Do not start new integrations with legacy endpoints.
</Warning>
