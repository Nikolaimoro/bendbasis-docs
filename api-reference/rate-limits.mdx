---
title: "Limits"
description: "Request limits and data updates"
---

Requests may return `429 Too Many Requests`. Retry with backoff.

## Data updates

- `GET /v1/funding/arbitrage`
  Windows refresh daily around 04:00 UTC.
- `GET /v1/funding/markets`
  Market data collection runs every minute.
- `GET /v1/funding/markets/{market_id}/history`
  History updates after exchanges publish funding payments.
