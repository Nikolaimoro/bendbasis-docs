---
title: "Limits and refresh cadence"
description: "Request, page-size, and refresh guidance"
---

The developer preview does not publish a fixed account request quota. Automated abuse protection can still return `429 Too Many Requests`. If this happens, reduce your request rate and retry with backoff.

`GET /v1/funding/arbitrage` returns 100 rows by default and accepts a maximum `limit` of 500.

`GET /v1/funding/markets` returns 100 rows by default and accepts a maximum `limit` of 1,000.

## Refresh cadence by endpoint

- `GET /v1/funding/arbitrage`
  The 7-day, 15-day, and 30-day windows are refreshed once per day (around 04:00 UTC). Polling more often does not provide fresher values.
- `GET /v1/funding/markets`
  Market metrics and funding APR windows are refreshed every five minutes.
