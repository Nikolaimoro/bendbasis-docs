---
title: "Backtest"
description: "Backtest a funding arbitrage pair"
openapi: "POST /v1/funding/arbitrage/backtest"
---

Settled funding events are used for the latest 30 days, and daily funding aggregates are used for older dates. If the selected range includes dates older than 30 days, the entire backtest series is grouped by UTC day.

```bash
curl -X POST "https://api.bendbasis.com/v1/funding/arbitrage/backtest" \
  -H "Content-Type: application/json" \
  -d '{"long_market_id":15036,"short_market_id":125}'
```
