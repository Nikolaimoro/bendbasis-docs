---
title: "Position"
description: "Get a position and its legs"
openapi: "GET /v1/positions/{position_id}"
---

Each leg includes its current quantity and latest available mark price. `funding.calculated` is the automatically accrued amount; when `funding.override` is present, it replaces the calculated amount in performance totals.

```bash
curl "https://api.bendbasis.com/v1/positions/POSITION_ID" \
  -H "Authorization: Bearer $BENDBASIS_API_KEY"
```
