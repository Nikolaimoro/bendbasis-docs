## Cursor pagination

Collection responses include the page data and an opaque cursor:

```json
{
  "data": [],
  "next_cursor": "eyJ2IjoxLC4uLn0"
}
```

When `next_cursor` is not `null`, send it as the next request's `cursor`. A `null` value means there are no more results. Keep the filters and sorting unchanged. Cursors are opaque. Data may refresh between pages.

## Errors

Errors use `application/problem+json`:

```json
{
  "type": "https://docs.bendbasis.com/api-reference/pagination-and-errors#errors",
  "title": "Invalid request",
  "status": 400,
  "detail": "Invalid limit; expected an integer between 1 and 500",
  "code": "VALIDATION_ERROR",
  "instance": "/v1/funding/arbitrage"
}
```
