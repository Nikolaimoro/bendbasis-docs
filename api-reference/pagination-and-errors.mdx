## Cursor pagination

Collection responses include a `pagination` object:

```json
{
  "limit": 100,
  "has_more": true,
  "next_cursor": "eyJ2IjoxLC4uLn0"
}
```

When `has_more` is `true`, send `next_cursor` as the next request's `cursor`. Keep all other filters and sorting parameters unchanged. Cursors are opaque and must not be modified.

## Errors

Errors use `application/problem+json`:

```json
{
  "type": "https://docs.bendbasis.com/api-reference/pagination-and-errors#errors",
  "title": "Invalid request",
  "status": 400,
  "detail": "Invalid limit; expected an integer between 1 and 500",
  "code": "VALIDATION_ERROR",
  "instance": "/v1/funding/arbitrage"
}
```
