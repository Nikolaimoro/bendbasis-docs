The BendBasis API reference is updated regularly to reflect changes to datasets, endpoints, and response formats. While development is active, check the documentation for the endpoints you use, as some details may change.

## Base URL

`https://api.bendbasis.com`

## Authentication

Authentication is not currently required.

## Example

```bash
curl "https://api.bendbasis.com/v1/funding/markets?base_assets=BTC&limit=10"
```
