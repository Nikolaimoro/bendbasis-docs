## Base URL

`https://api.bendbasis.com`

## Authentication

Market and funding endpoints do not require authentication.

Portfolio endpoints require a personal API key. Create one in [API keys](https://bendbasis.com/account/api-keys) and send it as a bearer token:

```http
Authorization: Bearer bb_api_...
```

## Example

```bash
curl "https://api.bendbasis.com/v1/markets?base_assets=BTC&limit=10"
```
